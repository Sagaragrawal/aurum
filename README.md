# Aurum Workspace

This workspace contains two independently buildable applications:

- `aurum-desktop/` — the production-reference Node.js desktop/web application.
- `aurum-android/` — the native Android 16 application.

Each application has its own README and build commands. Repository configuration uses public dependency repositories and contains no machine-specific proxy, SDK, or Artifactory settings. Configure corporate network access only in local shell or user-level tool configuration.
